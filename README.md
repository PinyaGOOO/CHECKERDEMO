# Web Demo Checker

Локальная панель автопроверки стенда демонстрационного экзамена. Текущая версия работает с тестовыми данными и подготовлена к подключению Proxmox, QEMU Guest Agent, SSH и сетевых проб.

## Запуск

Требуется Node.js 20 или новее.

```powershell
npm start
```

Откройте `http://localhost:8007`.

Для разработки с автоматическим перезапуском:

```powershell
npm run dev
```

## Режимы

- SSH-алиас задаётся через `CHECKER_SSH_ALIAS` и по умолчанию равен `checker`.
- При доступном алиасе состояние VM загружается из Proxmox через read-only команду `pvesh`.
- При недоступном SSH интерфейс автоматически продолжает работу с mock-инвентарём.
- Для запущенного `HQ-SRV (104)` через QEMU Guest Agent реально проверяются:
  - доступность агента;
  - hostname и IPv4/префикс;
  - состояния `chronyd`, `sshd` и `named`.
- Живые результаты отмечены меткой `LIVE`; остальные критерии пока демонстрационные.

Ожидания первого профиля: `hq-srv.au-team.irpo`, `192.168.10.10/27`.

## Развёртывание на Proxmox

На ноде служба использует `CHECKER_TRANSPORT=local`, вызывает `pvesh` и `qm` напрямую и слушает `0.0.0.0:8007`. Пример systemd unit находится в `deploy/web-demo-checker.service`.

Секреты Proxmox должны храниться только в локальном `.env`; браузеру они не передаются.
